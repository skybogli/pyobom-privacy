펴봄(Pyobom) 개인정보처리방침

시행일: 2026년 11월 25일 (4번 오류 기록·사용 통계 추가)
개발자: skybogli · 연락처: skybogli.dev@gmail.com

펴봄(이하 "앱")은 PDF·한글·워드·엑셀·PPT 문서를 폰 안에서 열고, 고치고, 스캔하는 앱입니다.
앱은 회원 가입이나 로그인이 없고, 광고를 넣지 않으며, 사용자의 문서나 사진, 파일 이름을 개발자 서버로 보내지 않습니다.
앱을 고치고 낫게 만들기 위해 오류 기록과 익명 사용 통계를 구글 Firebase로 보내며, 설정에서 언제든 끌 수 있습니다(아래 4번).

1. 앱이 다루는 정보와 쓰는 곳

정보쓰는 곳밖으로 보내는가
사용자가 연 문서·그림 파일화면에 보여 주기, 고치기, PDF로 바꾸기보내지 않음(폰 안에서만 처리)
카메라 사진(스캔할 때만)문서 스캔·PDF 만들기보내지 않음
폰 저장공간의 문서·그림 파일 목록(모든 파일 접근을 허용했을 때) 또는 사용자가 고른 폴더의 파일 목록파일 탭에 문서·그림 모아 보기보내지 않음
최근 연 파일·즐겨찾기·설정다음에 다시 열기 편하게보내지 않음(앱 안에만 저장)
앱 안 오류 기록(앱이 꺼졌을 때)문제 고치기사용자가 직접 [공유]를 누를 때만 사용자가 고른 곳으로 (4번 Firebase 오류 기록과 별개)

2. 권한

  • 카메라: 앱 안 스캔 기능을 쓸 때만 묻습니다. 찍은 사진은 폰 안에만 남습니다.
  • 모든 파일 접근(선택): 허용하면 폰 저장공간에 있는 문서·그림을 찾아 파일 탭에 모아 보여 줍니다. 파일 목록과 내용은 폰 안에서만 쓰고 밖으로 보내지 않습니다. 안드로이드 설정에서 언제든 끌 수 있습니다.
  • 폴더 접근: 모든 파일 접근을 허용하지 않으면 사용자가 파일 탭에서 직접 고른 폴더만 봅니다. 고른 폴더는 언제든 [관리 → 빼기]로 뺄 수 있습니다.
  • 인터넷: 구글 ML Kit(문서 스캐너·글자 인식)가 필요한 모델을 받거나 아래 3번 정보와 4번 오류 기록·사용 통계를 보낼 때 씁니다. 앱 자체는 문서를 인터넷으로 보내지 않습니다.

3. 구글 ML Kit

문서 스캔(테두리 찾기)과 글자 인식(OCR)은 구글 ML Kit를 씁니다. 그림과 글자는 폰 안에서 처리되며 구글로 보내지 않습니다.
다만 글자 인식·스캔을 쓸 때 ML Kit는 진단과 사용 분석을 위해 다음 정보를 구글에 보냅니다.

  • 기기 정보(제조사·모델·OS 버전)와 앱 정보(앱 이름·버전)
  • 기기 ID와 설치할 때마다 새로 정해지는 ID
  • 성능(처리 속도)·설정·오류 코드 같은 사용 정보

이 정보는 HTTPS로 암호화해 보내며, 구글은 이를 다른 회사에 넘기지 않는다고 밝히고 있습니다.
자세한 내용: https://developers.google.com/ml-kit/android-data-disclosure

4. 오류 기록과 사용 통계 (Google Firebase)

앱이 꺼지는 문제를 찾아 고치고, 어떤 기능을 더 낫게 만들지 정하기 위해 구글 Firebase의 Crashlytics(오류 기록)와 Google Analytics for Firebase(사용 통계)를 씁니다.

보내는 정보목적보관 기간
오류 기록: 앱이 꺼진 때의 코드 위치, 앱 버전, 기기 모델·OS 버전, 메모리·저장공간 상태, 앱 설치마다 정해지는 무작위 ID앱이 꺼지는 원인 찾기90일
사용 통계: 앱을 연 횟수·사용 시간, 연 문서의 종류(PDF·한글 등), 쓴 PDF 도구의 이름(합치기·나누기 등), 기기 모델·OS 버전·언어, IP 주소로 짐작한 나라·지역, 앱 설치마다 정해지는 무작위 ID많이 쓰는 기능 알기, 앱 개선2개월
  • 보내지 않는 것: 파일 이름·경로·문서와 사진의 내용, 이름·전화번호·이메일 같은 개인 정보, 광고 ID.
  • 끄기: 앱 설정 › 파일 › 동작 › '앱 개선 정보'에서 '오류 기록 보내기'·'사용 통계 보내기'를 끌 수 있습니다. 끄면 그때부터 보내지 않으며, 꺼도 앱의 모든 기능을 그대로 쓸 수 있습니다.
  • 유럽 등: 유럽 연합·유럽 경제 지역·영국·스위스에서는 사용 통계를 처음에 꺼 두고, 처음 실행할 때 보낼지 묻습니다.

국외 이전 (개인정보 보호법 제28조의8)

  • 이전받는 자: Google LLC (연락처: https://support.google.com/policies/contact/general_privacy_form)
  • 이전 국가: 미국 등 구글이 데이터 센터를 둔 나라
  • 이전 항목·목적·보관 기간: 위 표와 같음
  • 이전 시기·방법: 앱을 쓰는 동안 수시로, HTTPS로 암호화해 네트워크로 보냄
  • 거부 방법과 거부할 때 불이익: 위 '끄기' 방법으로 거부할 수 있고, 거부해도 불이익이 없습니다.

자세한 내용: https://firebase.google.com/support/privacy

5. 보관과 지우기

앱이 만든 기록(최근 목록·설정·앱 휴지통·글자 인식 결과)은 폰 안 앱 저장 공간에만 있습니다.
앱 휴지통의 파일은 30일 뒤 저절로 지워지며, 앱을 지우면 앱이 만든 기록도 모두 지워집니다.

6. 아이

앱은 아이를 대상으로 하지 않으며, 아이의 개인정보를 따로 모으지 않습니다.
